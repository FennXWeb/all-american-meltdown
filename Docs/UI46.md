# UI update 46

## Player HUD

The bottom loadout strip displays silhouettes of the weapons actually equipped in slots 1–4, with rarity colors and an active-weapon indicator. Wearing a chest rig adds slot 5 for its extra primary weapon. Empty slots show a dash. The H medkit indicator displays the number of usable medkits and dims when none are available. This strip is shown on foot; vehicle controls retain their own HUD.

## Shelter terminal

Shelter Control is now a compact wall-mounted CRT terminal beside the bunker entrance, with a shallow metal housing, inset screen, bezel, and keyboard. Its interface uses green text, scanlines, and a highlighted selection.

- Arrow keys move between controls.
- Enter activates the selected control.
- Escape closes the terminal.
- Mouse clicks remain supported.

Furniture, expansions, assignments, and garage actions retain their existing functionality.

## Main menu

The main menu uses an animated ruined skyline with a tattered flag, flickering windows, drifting ash, haze, and scanlines. The procedural world and bunker are generated only when a new game or saved game starts. The pause menu still displays the current game behind it.

## Build camera

Mouse look now follows the normal vertical direction and scales with the player's mouse sensitivity setting. WASD movement stays horizontal regardless of camera pitch; Space and Ctrl change height, and Shift moves faster.
