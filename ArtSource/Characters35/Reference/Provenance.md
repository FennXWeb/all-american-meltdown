# Anatomical reference

The hm08 base mesh is a CC0 graphical asset from the MakeHuman project. No MakeHuman application code is included or linked. The game head meshes are modified, reduced and remapped derivatives of its body and eye geometry. Clothes, grooming, accessories, gameplay code and the import pipeline are project assets.

Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj
