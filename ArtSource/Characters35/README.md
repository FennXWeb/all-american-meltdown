# Character source library

96 modular character meshes for the revision 35 survivor creator and humanoid NPCs. Units are metres in Blender and centimetres in Unreal; +X is forward. Runtime assembly and morphs are in LWAppearance.cpp and LWCreator35.cpp.

Anatomical head geometry derives from the CC0 MakeHuman hm08 mesh. See Reference/Provenance.md and Reference/CC0-1.0.md. Clothing, grooming, accessories and assembly geometry are built by Tools/make_characters35.py.

Use Tools/import_characters35.py in Unreal to import and validate the assets. Full controls and verification notes are in Docs/CharacterCreator35.md. No packaging is performed.
