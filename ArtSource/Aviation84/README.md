# Aviation 84 source assets

Original meshes are authored in `Tools/build_aviation84.py` and saved in `Aviation84.blend`. FBX files, pivot coordinates, material slots, bounds and Blender source are included. The hulls use continuous double-wall lofts with openings, shaped airfoil sections, swept fins and turbine vanes. Cabin furnishings are separate selectable components. Seat bases and hinged backs are separate; overhead compartment fronts and suite doors animate independently.

`Tools/import_aviation84.py` imports the assets into Unreal, checks their imported bounds and material slots, creates LODs, imports the atlas, and builds the aviation and explosion materials. It does not package the project.

`T_AviationAtlas84.png` was generated using the image-generation tool for this update. It contains four material studies: ivory upholstery, dark navy carpet, pearl aircraft metal and walnut. The runtime materials sample the quadrants individually and combine them with material-specific colors and roughness. Original generated output: `exec-26ac8dca-d614-42c9-acc7-fea7ab64ca13.png`; mode: new image generation. This is a material atlas, not a photograph of a real aircraft.

The turbine and cockpit warning WAVs are original synthesized audio generated by the importer. The turbine uses periodic harmonics and a periodic broadband component to avoid a hard loop seam. Both are replaceable through `AircraftTurbine84` and `AircraftWarning84` in the existing audio catalog, including its Tracks list.

Aircraft branding and exterior/interior styling are original game designs. The standard airliner provides 100 seats including both cockpit seats. The private jet has eight seats; the luxury airliner has 16 seating positions including its usable lounge couch, plus sleeping furnishings.

`Tools/validate_aviation84.py` runs in Blender against the saved source file and verifies forward visibility from all three pilot seats. `Tools/import_aviation84_meshes.py` reimports only the three hulls while retaining materials and audio.
