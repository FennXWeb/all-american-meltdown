# Survivor Network furniture

Seven original low-poly meshes generated in Blender 4.2 by `Tools/make_models_v4.py`: locker, refrigerator/water station, stove, communications radio rack, workshop bench, sink and toilet. Models use worn material slots already established in the project. The Blender source scene and individual FBXs are supplied alongside the manifest. `Tools/import_models_v4.py` handles Unreal centimeter scaling, material assignment and collision.
